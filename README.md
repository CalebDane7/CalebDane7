## 🔒 KittyAI Controller

Your AI coding agent is one hallucination away from breaking production.

KittyAI puts 24 hard gates between the agent and your codebase. Every tool call — every file edit, every shell command, every git push — gets intercepted and verified *before* it executes. Pre-tool hooks catch bad intent. Post-tool hooks catch bad output. Nothing ships without passing.

This isn't linting. This is enforcement.

## 🌐 agent-browser

Your AI agent builds a feature. How does it know the feature actually works?

agent-browser gives it eyes. CLI browser automation straight through Chrome DevTools Protocol. Screenshots, DOM snapshots, click, type, fill forms, verify results — all from the terminal. Your agent writes the code, then tests it like a real user would. Direct CDP connection. Fast. Zero bloat.
